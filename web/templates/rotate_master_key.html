Rotate the master key

Runs at your next login

Changing your password or issuing a new recovery key replaces the wrapper around your master key — the key itself stays the same. Rotation replaces the key itself. Everything in your practice file is re-encrypted under a brand-new master key, and a new recovery key is issued.

Afterwards, none of these can open your current records any more:

  • an old copy of your key file (from a lost laptop, an old backup, or a synced folder) together with the password of the day;
  • any previous password;
  • your current recovery key — you will be given a new one to write down.
This does not protect old backups. A backup made before the rotation is a complete snapshot that still opens with the password and recovery key from that time. If you are rotating because something may have been copied, also decide what to do about backups made before the copy — rotation is not a substitute for backup hygiene.

Nothing changes now. The rotation runs the next time you log in, behind a progress screen, and takes a safety backup first if there is none from the last 24 hours. Have somewhere secure to write before you start that login — the new recovery key is shown once.
