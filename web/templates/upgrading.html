Encryption upgrade

One-time security upgrade

EdgeCase is adding a recovery key — a printed code that can open your records if you ever forget your master password. Without one, a forgotten password means the records are gone for good.

This runs once and re-encrypts your practice file, so it can take a few minutes. Please don't close the app while it works.

Have somewhere secure to write before you start — the key is shown once at the end and is never stored.
