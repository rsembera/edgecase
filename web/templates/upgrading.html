Securing your practice

One-time setup

EdgeCase is encrypting your new practice file and creating a recovery key — a printed code that can open your records if you ever forget your master password. Without one, a forgotten password means the records are gone for good.

This runs once and only takes a moment on a new practice. Please don't close the app while it works.

Have somewhere secure to write before you start — the key is shown once at the end and is never stored.
